# WR-MovementIQ Notebook 15 — Supporting Artifacts

This bundle contains derived result tables, manifests, and publication PNG
figures required by the public research notebook.

It does not contain original raw NFL competition tracking data.

Preserve the reports/ directory structure when attaching this bundle to a
hosted notebook environment.

The notebook is a results and audit presentation, not a complete raw-data
feature reconstruction or model-refitting pipeline.
